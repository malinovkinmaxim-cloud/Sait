# Максим · Mandarin — портфолио веб-разработчика

Сайт-портфолио (RU / EN) и три сайта-кейса для реальных заведений Москвы.

Порядок блоков на главной: первый экран → проекты → «Что я могу сделать» →
«Обо мне» → процесс работы → финальный призыв «Обсудить проект» и контакты.

## Как открыть

Сборка не нужна: откройте `portfolio/index.html` в браузере.
Или запустите локальный сервер в корне репозитория:

```bash
python3 -m http.server 8000
# http://localhost:8000/portfolio/
```

## Структура

```
portfolio/
├── index.html                 портфолио
├── assets/                    стили, скрипты, шрифты, превью кейсов
│                              (img/*-tall-*.webp — скриншоты, которые
│                              прокручиваются при наведении)
└── projects/
    ├── restaurant/            Project 01 — MANUL, ресторан кухни народов Сибири
    ├── barbershop/            Project 02 — MATTO, барбершоп
    └── beauty-salon/          Project 03 — A&Ю, студия красоты
```

Каждый проект самостоятельный: свои `css/`, `js/`, `fonts/`, `images/`. Шрифты и
изображения лежат локально, внешних зависимостей нет.

## Что настроить

- **Контакты** (Telegram и email) заданы в `portfolio/index.html`: в блоке
  «Контакты», в мобильном меню и в главной кнопке «Обсудить проект», которая
  открывает чат в Telegram. Если контакты поменяются, их нужно обновить во всех
  трёх местах.
- **Фото ресторана.** Реальные фото MANUL скачать не удалось: сетевые правила
  окружения, в котором собирался сайт, блокируют сайт ресторана и фотохостинги.
  Вместо фото сейчас SVG-иллюстрации. Чтобы подставить фото, положите файл в
  `portfolio/projects/restaurant/images/` и укажите путь в атрибуте
  `data-photo="images/…"` у нужного блока в `index.html`. Это три панели в разделе
  «Зал» и скрытый блок с фото шефа.

## Языки

Русский текст хранится прямо в HTML, английский лежит в `js/content.js`
(`window.I18N.en`). Выбранный язык запоминается и передаётся между портфолио и
проектами через `?lang=en`.

## Данные

Названия, адреса, часы работы, цены, команды и фото взяты из открытых источников:
официальные сайты (manulmoscow.ru, aystu.ru), 2ГИС, Яндекс Карты, Zoon, Афиша.
Сайты-кейсы — концепты для портфолио, а не официальные сайты заведений: об этом
сказано в подвале каждого из них, а формы записи ничего не отправляют.
